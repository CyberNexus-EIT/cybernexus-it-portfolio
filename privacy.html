04 / Security

Data Protection

Reasonable technical and organizational measures should be applied to protect information.

The platform is designed with security in mind. Depending on the deployment and enabled features, safeguards may include access controls, authentication, secure communications, protected credentials, input validation, logging, backups, monitoring, and security testing.

No internet-connected system can guarantee absolute security. Security controls should therefore be continuously reviewed, tested, maintained, and improved.
